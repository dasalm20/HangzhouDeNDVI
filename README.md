# GEOG 652 Final Project: Vegetation Change in Hangzhou, China

Landsat-based analysis of vegetation density change in the Hangzhou urban centre,
1995 to 2025, for GEOG 652 (Satellite Remote Sensing Systems), University of Maryland.

The analysis is written in Python but mirrors a standard ENVI workflow stage for
stage. Each script header names the ENVI equivalent of what it does.

## Study area

- Hangzhou, China: the GHSL 2015 urban centre, buffered by 5 km
- Area: 3,291.58 km2
- Note: this is **not** the Hangzhou administrative municipality and is smaller,
  so published municipal green-coverage figures are not directly comparable

## Scenes

All three scenes are Tier 1, path/row 119/039, and fall within 10 calendar days of
each other in August, which keeps crop stage and sun angle broadly comparable.

| Year | Sensor | Date | Scene ID | Usable after QA |
|---|---|---|---|---|
| 1995 | Landsat 5 | 1995-08-03 | LT05_L2SP_119039_19950803_02_T1 | 98.69% |
| 2010 | Landsat 5 | 2010-08-12 | LT05_L2SP_119039_20100812_02_T1 | 98.20% |
| 2025 | Landsat 9 | 2025-08-13 | LC09_L2SP_119039_20250813_02_T1 | 95.34% |

Analysis grid: EPSG:32651, 30 m, 2751 x 2409 pixels.

## Processing chain

| Script | Does | ENVI equivalent |
|---|---|---|
| `00_config.py` | All shared settings. No processing logic. Run directly to create folders and print a setup summary. | n/a |
| `01_get_landsat.py` | Download the three scenes | File > Open As > Optical Sensors > Landsat |
| `02_inspect.py` | Metadata, coverage and histograms | Raster Metadata viewer, Histogram tool |
| `03_clean.py` | Scale to reflectance, apply QA masks, reproject | Radiometric Calibration, then Reproject Raster |
| `04_indices.py` | NDVI and NDBI, plus between-date differences | Band Math, or Spectral Indices |
| `05_figures.py` | RGB, index and change maps | Display groups with linked views |
| `06_validation.py` | Visual check of candidate change sites | Cursor Location / Value, linked windows |
| `07_classify.py` | Unsupervised classification, all three dates | ENVI Classic: Classification > Unsupervised > K-Means |
| `08_change.py` | Post-classification change detection | ENVI Classic: Basic Tools > Change Detection |
| `09_accuracy.py` | Error matrix, producer's and user's accuracy, Kappa | ENVI Classic: Post Classification > Confusion Matrix |
| `10_export_envi.py` | Export reflectance, NDVI and class rasters as ENVI flat binary, plus `expected_values.txt` for cross-checking against ENVI | n/a |
| `study_area.py` | Build the study-area boundary from GHSL and draw the context map | n/a |

Only `02-Scripts/` is tracked in git. Imagery and derived rasters are large and
fully reproducible from the scripts, so they stay out of the repository.

pair of an extensionless data file and a `.hdr` header (for example
`reflectance_1995` and `reflectance_1995.hdr`). Both must be kept together, and
the extensionless file is easy to lose to a careless cleanup.

## Environment

The virtual environment is **not** tracked and must be built locally. A venv is
platform-specific, so one created on macOS will not run on Windows.

```bash
# macOS / Linux
python3.11 -m venv ~/venvs/geog652
source ~/venvs/geog652/bin/activate
```

```powershell
# Windows
py -3.11 -m venv "$env:USERPROFILE\venvs\geog652"
& "$env:USERPROFILE\venvs\geog652\Scripts\Activate.ps1"
```

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

Keep the environment on local disk rather than inside the Google Drive folder.
Drive's on-demand streaming can fail part way through a binary import.

`requirements.txt` is a full `pip freeze` from the macOS environment, so a few
pinned versions may not resolve on Windows. If the install fails, the packages the
scripts actually import are:

```
numpy pandas rasterio geopandas matplotlib scikit-learn
pystac-client planetary-computer ipykernel
```

## Running it

```bash
cd 02-Scripts
python 00_config.py        # creates folders, prints a setup summary
python 01_get_landsat.py
python 02_inspect.py
python 03_clean.py
python 04_indices.py
python 05_figures.py
python 06_validation.py
python 07_classify.py
python 08_change.py
python 09_accuracy.py
python 10_export_envi.py
```

Run in order. Each stage reads the previous stage's output from `03-Output/`.

`study_area.py` is a standalone helper rather than a numbered stage. It builds the
study-area boundary from the GHSL geopackage and draws the context map, so run it
before the stages that need the boundary.

## Classification

Five classes. They are named for vegetation density rather than land cover,
because the classification is built from NDVI alone, so a class describes how
much vegetation a pixel holds, not what the surface is.

| Code | Class | Meaning |
|---|---|---|
| 1 | water | from the QA water mask, not from NDVI |
| 2 | low_veg | lowest NDVI, mostly built-up and bare surfaces |
| 3 | moderate_veg | built-up with scattered trees or grass |
| 4 | mixed_veg | fields, grass, open or patchy vegetation |
| 5 | dense_veg | closed canopy |

NDVI class boundaries from the pooled K-Means fit: 0.269, 0.474, 0.666.

## Known limitations

These are carried into the report rather than hidden.

1. **2010 is excluded from the quantitative change analysis.** Scene mean NDVI is
   0.4875 in 2010 against 0.5322 in 1995 and 0.5193 in 2025. That 0.045 offset is
   roughly a fifth of a class width, enough to shift class areas with no real
   landscape change. 2010 is still classified, mapped and discussed. The change
   pair is 1995 to 2025, which differ by only 0.013.
2. **NDBI is reported but not used to build the classification.** The 1995 scene
   sits about 0.045 lower in SWIR1 at every percentile, which depresses its NDBI
   independently of land cover.
3. **The QA_PIXEL water bit is inconsistent between dates.** It flagged 105.7 km2
   in 1995, 52.8 km2 in 2010 and 124.6 km2 in 2025, and in 2010 it missed most of
   the Qiantang River. Turbid river water is not reliably flagged. Found by
   inspecting the unsupervised clusters, not by the QA band.
4. **Accuracy sample size is below the recommendation.** 20 samples per class,
   where Lecture 6 recommends 50 to 100. Samples are 3 x 3 blocks spaced at least
   20 pixels (600 m) apart to limit spatial autocorrelation.

## Data sources

- Landsat Collection 2 Level-2 surface reflectance, USGS. Scaling factors and
  QA_PIXEL bit definitions from the Landsat Collection 2 Level-2 Science Product Guide.
- Scenes accessed through the Microsoft Planetary Computer STAC API.
- Study-area boundary from the GHSL Global Urban Centre Database R2024A V1_2,
  European Commission Joint Research Centre.
- Country outlines for the study-area context map from Natural Earth,
  1:50m Admin 0 Countries. Used for cartography only, not in the analysis.

## Reproducibility

Random seed is fixed at 42 throughout, so the K-Means classification and the
accuracy sample are reproducible.
